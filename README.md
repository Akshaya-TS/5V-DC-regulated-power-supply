# 5V-DC-regulated-power-supply
Designed a regulated 5V DC power supply using KiCad, including schematic design, footprint assignment, PCB layout, routing, DRC, and Gerber generation. The circuit uses a full-wave rectifier to convert AC to DC, a filter capacitor to reduce ripple, and a 7805 voltage regulator to provide stable 5V DC output for embedded and electronic applications.
